# Instructions for AI agents

This repository holds the standard operating procedures (SOPs) for tricot on-farm trials, each generated from a ClimMob project template. It is the protocols layer of the [AI-ready documentation suite](https://github.com/AgrDataSci/ai-ready-documentation) and also works on its own. If a user shares this repository with you, use it as follows.

1. Read `SKILL.md` first. It says how to find the protocol for a crop and how to answer which questions it uses.
2. Resolve the crop in order. The crop's own protocol, then its crop group, then the `core` protocol. Tell the user which level answered.
3. Read questions from `protocols/<protocol_id>/questions-<lang>.csv`. Do not parse the Word documents when a question file exists.
4. Check the `status` in `protocols.csv`. A `placeholder` protocol has no published questions yet. Say so, and label any questions you borrow from another protocol.
5. Never invent a question, trait, plot size, data collection moment, DOI or author.
6. Fetch `version.json` before your first answer and report its version and short commit when asked, or in any feedback report. Never invent a commit.
7. Cite each SOP by the concept DOI in `protocols.csv`, or the collection DOI when it has none.

## Rules for editing

- `protocols.csv` is the single source of truth. Keep `data/crops.csv` and `data/crop-groups.csv` consistent with it.
- Question files and SOP documents are generated by `script/01-render-protocols.R` from ClimMob. Never edit them by hand.
- R code uses `=` for assignment.
